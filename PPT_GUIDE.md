# PART E — DESIGN SPEC FOR PPT

## Color System (match the app exactly)

| Element | Color | Hex |
|---------|-------|-----|
| Background | Deep navy | `#0A0F1E` |
| Card background | Darker navy | `#0F1629` |
| Primary accent | Indigo | `#6366F1` |
| Text primary | White | `#FFFFFF` |
| Text secondary | Slate | `#94A3B8` |
| Warning | Amber | `#F59E0B` |
| Success | Emerald | `#10B981` |
| Danger/Alert | Rose | `#F43F5E` |
| Opportunity | Indigo light | `#818CF8` |

## Typography
- Headings: **Inter Bold** or **Poppins Bold**, size 40-60pt
- Body: Inter Regular, size 16-20pt
- Stats/Numbers: Inter Black, size 72-96pt (make them huge)
- Labels: Inter Medium, uppercase, letter-spacing wide

## Layout Rules
- Dark background always
- One big idea per slide
- Numbers HUGE — text small
- Diagrams over bullet points always
- Use the ecosystem arrow diagram on EVERY slide as a small footer/watermark for brand recall
- Actual screenshots > mockups
